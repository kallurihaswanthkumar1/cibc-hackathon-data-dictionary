# CIBC Hackathon - Data Dictionary

Read-only extract of the Google Sheet "CIBC Hackathon - Data Dictionary". Source sheet was not modified.

- `data/about.csv`: About sheet
- `data/tables.csv`: Tables sheet (31 tables)
- `data/relationships.csv`: Relationships sheet (48 links)
- `data/columns_partial.csv`: Columns sheet, first 51 of 1,421 rows (customers table only)
- `docs/CIBC_Hackathon_Data_Dictionary.pdf`: all of the above as a PDF
- `build_pdf.py`: regenerates the PDF from the CSVs
